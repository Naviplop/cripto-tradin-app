# User Manual - Crypto Trading Terminal LAFM

## Quick Start

1. **Activate** with your license key.
2. **Load** the local ONNX model (`trading_model.onnx`) — optional, falls back to heuristics.
3. **Choose** Paper Trading mode for simulation or connect your Binance API.
4. **Monitor** real-time signals generated by the Edge AI engine.

---

## 1. Creating Your Binance API Key (Step by Step)

1. Open [Binance API Management](https://www.binance.com/en/my/settings/api-management).
2. Click **Create API**.
3. Label: `LAFM Trading Terminal`.
4. Under **API Restrictions**, select:
   - **Enable Reading**
   - **Enable Spot & Margin Trading**
5. Under **Withdrawal Restrictions**, ensure **NO** withdrawal permissions are enabled.
6. Copy the **API Key** and **Secret** and paste them into the application configuration.
7. Confirm creation with your 2FA device (Google Authenticator / SMS).

**Security Note:** Never share your API Secret. The application encrypts credentials locally using AES-256 and never transmits them to external servers.

## 2. Interpreting the AI Control Panel

| Signal | Meaning |
|--------|---------|
| **BUY** | Technical analysis and ONNX probability favor a long position. |
| **SELL** | Combined analysis suggests closing or shorting. |
| **HOLD** | Insufficient confidence to act. Recommended to wait for stronger confluence. |
| **STRONG_BUY / STRONG_SELL** | High-confidence signal backed by multiple indicators and AI. |

### Indicators

- **RSI (14):** Momentum oscillator. Below 30 = oversold (potential BUY). Above 70 = overbought (potential SELL).
- **MACD:** Trend-following momentum. Crossovers signal potential entry/exit points.
- **ATR (14):** Average True Range measures volatility. Higher values suggest wider Stop Loss / Take Profit ranges.
- **EMA(10/30):** Fast/slow moving average crossover for trend direction.

### ONNX Confidence Score

The AI probability ranges from **0.0 to 1.0**:

- **0.7 – 1.0:** High confidence. Consider full position size.
- **0.5 – 0.69:** Moderate confidence. Consider reduced sizing or wait for confirmation.
- **0.0 – 0.49:** Low confidence. HOLD and wait for confluence.

## 3. Auto-Execution vs Alerts Mode

| Mode | Behavior |
|------|----------|
| **Auto-Execute** | System automatically places market orders when AI emits BUY/SELL. TP/SL attached to every position. |
| **Alerts Only** | Signals displayed visually but no orders sent. Recommended for manual review. |

To switch modes, open **Settings** in the Trading Panel and toggle **Auto-Execution**.

---

## 4. Managing API Keys

1. Open the application Settings.
2. Enter your **API Key** and **API Secret**.
3. Toggle **Paper Trading** if you want to simulate without live credentials.
4. Click **Save**.

Keys are encrypted with AES-256 using a key derived from your machine's Hardware ID (HWID). They are stored in `%APPDATA%/LAFM/secure.db` and never leave your computer.

---

## 5. License Activation

1. Launch the application.
2. On the license screen, paste your license key or click **Load .lic file**.
3. Click **Activate License**.
4. The backend validates the HWID match and HMAC-SHA256 signature.
5. If valid, the main dashboard loads automatically.

**Note:** Licenses are bound to your machine's Hardware ID. If you change computers, contact LAFM support for a transfer.

---

## 6. Model Updates

The ONNX model can be updated without reinstalling the application:

1. LAFM publishes a new model file.
2. The application downloads it to `%APPDATA%/LAFM/models/trading_model.onnx`.
3. The AI engine reloads the model on the next tick.
4. Future predictions use the updated weights.

## 7. Frequently Asked Questions

### Privacy

**Q:** Does LAFM have access to my API keys?  
**A:** No. API keys are encrypted locally using AES-256. LAFM servers never receive, store, or transmit your credentials.

### Connectivity

**Q:** What happens if my Internet connection drops?  
**A:** The WebSocket client features automatic exponential backoff reconnection with jitter. During disconnection, the last known signals and account state remain visible. Orders already placed on the exchange remain active.

### Paper Trading

**Q:** Can I test without depositing funds?  
**A:** Yes. Paper Trading mode simulates a $10,000 USDT portfolio with real-time market data and ONNX inference without requiring exchange API credentials.

### License

**Q:** What if I change computers?  
**A:** License keys are bound to your machine's Hardware ID (HWID). Contact LAFM support to request a license transfer.

### Auto-Updates

**Q:** How does the app update?  
**A:** The Electron wrapper checks for updates silently on startup. When a new version is available, it downloads in the background and installs on next restart.
